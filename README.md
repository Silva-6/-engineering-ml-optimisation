\# Engineering ML Optimisation



A research-oriented computational project exploring machine learning, optimisation, reinforcement learning, numerical modelling, and intelligent decision-making for complex engineering and cyber-physical systems.



\## Objectives



\- Build strong scientific Python foundations

\- Implement optimisation algorithms from first principles

\- Implement evolutionary computation methods

\- Develop reinforcement learning methods from first principles

\- Apply these methods to simulated engineering systems

\- Compare learning-based and optimisation-based approaches under uncertainty
